# Sistema de Cardápio Digital

## Sobre o projeto

Este projeto consiste em um sistema de cardápio digital desenvolvido em Python com o framework Flask, utilizando SQLite para o armazenamento dos dados.

O sistema foi criado para uma lanchonete, com o objetivo de facilitar o gerenciamento dos produtos e permitir que os clientes consultem o cardápio de forma prática, tanto pelo computador quanto pelo celular.

## Funcionalidades

O sistema possui duas áreas principais.

**Cardápio digital:**
- Visualização dos produtos por categorias.
- Exibição de imagens, descrições e preços.
- Cadastro de produtos individuais e combos.
- Layout responsivo para dispositivos móveis.
- Integração com WhatsApp para contato.

**Painel administrativo:**
- Acesso por autenticação.
- Cadastro de novos produtos.
- Edição e exclusão de produtos.
- Upload de imagens.
- Atualização de preços.
- Controle de disponibilidade dos produtos.

## Tecnologias utilizadas

- Python
- Flask
- SQLite
- SQLAlchemy
- HTML5
- CSS3
- Jinja2

## Objetivo do sistema

A ideia principal foi desenvolver uma aplicação simples de utilizar, permitindo que o proprietário da lanchonete administrasse seu cardápio sem precisar ter conhecimentos de programação.

Com o painel administrativo, o próprio estabelecimento consegue atualizar produtos, modificar preços e controlar a disponibilidade dos itens.
